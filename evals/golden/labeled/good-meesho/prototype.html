One webhook layer for meesho.com payment operations.
Razorpay can receive or emit event payloads around the objects your engineering and finance teams already reason about: marketplace orders, seller splits, payment captures, refunds, COD remittances and payouts.
payment.captured refund.processed cod.settlement.received seller.payout.created 
razorpay.webhooks.on("payment.captured", async (event) => {
  const { order_id, payment_id, method, amount } = event;

  await meeshoReconciliation.upsert({
    meesho_order_id: order_id,
    razorpay_payment_id: payment_id,
    payment_method: method, // upi, card, cod
    gross_amount: amount,
    state: "payment_matched"
  });
});

razorpay.webhooks.on("refund.processed", ({ order_id, refund_id, amount }) => {
  meeshoReconciliation.matchRefund({
    meesho_order_id: order_id,
    razorpay_refund_id: refund_id,
    refund_amount: amount
  });
});

razorpay.webhooks.on("cod.settlement.received", ({ order_id, settlement_id }) => {
  meeshoReconciliation.markCodSettled({
    meesho_order_id: order_id,
    cod_settlement_id: settlement_id
  });
});
